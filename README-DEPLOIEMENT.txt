BIKE & PUNCHLINE v1.2.0

Cette archive est une MISE A JOUR SANS MEDIAS HISTORIQUES.
1. Décompresser par-dessus le dossier maître BikePunchline qui contient assets/media.
2. Envoyer le dossier complet dans le dépôt GitHub michaelpeyrin-design/bikepunchline.
3. Connecter ce dépôt à Netlify. Build command: node build.js ; Publish directory: .
4. Pour Decap CMS /admin/, créer une GitHub OAuth App puis installer GitHub comme Authentication provider dans Netlify.
5. Les nouvelles images ajoutées depuis Decap seront enregistrées dans assets/media/uploads.

IMPORTANT : si le dépôt GitHub est déployé sans les anciens assets/media, les anciennes photos ne seront pas présentes dans le nouveau déploiement Netlify.
